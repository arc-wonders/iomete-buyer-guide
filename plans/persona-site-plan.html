IOMETE, explained for you

01 · The idea

Same atoms, three readers, one truth table

iomete.com has one headline for twelve product pages and no idea who is reading. Our version keeps IOMETE's lime-on-green, Archivo headings and isometric diagrams, but every component is re-captioned and re-weighted per persona. The bot does not write essays. It answers in two sentences and moves the page to the component that proves it.

Every fact rendered on the page carries one of three states, and the bot shares the same store:

documented

Backed by a docs, legal or pricing URL. Example: Enterprise is $500 per vCPU per year with a $100,000 minimum.

claimed

IOMETE marketing, quoted with attribution. Example: “Save 2–5x over SaaS/cloud” on the homepage, “30–60%” in the FAQ.

unknown

Not in any public source. We say so and route to the Vanta trust center or a contact. Example: SOC 2 Type II, breach-notification window, SBOM.

Persona assumption to confirm. FDE is read as the engineer who would install and run it. CRO is read as Chief Risk Officer, who signs off on a data platform at the banks and insurers IOMETE sells to. If Chief Revenue Officer was meant, the door's content changes but the build does not. Personas live in one JSON file.

02 · The 15-second landing

One screen, three beats, no scroll

The visual is the lime hexagon network diagram already on IOMETE's homepage, animated. The picture never changes by persona. Only the captions do.

0–5 s

The frame draws itself. The lime IOMETE mark lands inside it. Caption: “A data lakehouse that runs inside your own infrastructure.”

5–10 s

Two grey SaaS marks sit outside with dotted lines pulling data out. The lines are cut. Caption: “Your data never leaves. No vendor can see it. No bill per query.”

10–15 s

Three doors slide up with one line each, plus a single input for the bot. Picking a door or typing a sentence both lead to the same persona page.

05 · The bot

A navigator, not a chatbot

Input
One sentence on landing, or a follow-up question on any door.
Output
Two sentences max, a state chip, one source link, and a page action: scroll to atom, highlight fact, or switch door.
Grounding
Retrieval over github.com/iomete/iom-docs (MDX mapped to iomete.com/resources/… URLs, internal_docs/ excluded), the 44 marketing pages, 38 FAQ items, 3 policies and pricing. About 500 documents, so BM25 or a small embedding index is enough. Authority order: release notes, then deployment and user guide, then legal and pricing, then FAQ and llms.txt, then homepage and blog. Third-party aggregators excluded.
Facts store
content/facts.json: one record per claim with id, text, state, source URL, quoted span, tier and fetch date. UI components render by fact id, so hover citations and the bot share one truth.
Refusal list
Enforced in code, not prompt. A post-check rejects any answer stating a savings percentage, a certification beyond SOC 2 Type I, “no telemetry”, a named customer, a docs.iomete.com URL, or a headcount or funding figure, unless wrapped as an attributed claim with its URL.
Model
Claude via the Messages API with four tools: navigate, highlight, switch_persona, cite. Persona is system context, so the same question yields a different door and tone.
06 · Architecture

Small, embeddable, handoff-ready

Frontend

Next.js and Tailwind with IOMETE's tokens as CSS variables and self-hosted fonts. Single route, persona in the URL (/?p=cro) so a rep can send a link. Framer Motion for the hero. IOMETE images referenced by CDN URL, not re-hosted.

Content

personas.json (door order, captions, atom list), facts.json, and per-atom copy files. No CMS in v1.

Backend

One API route for the bot (retrieval, Claude, post-check) and one for PDF export. A script clones iom-docs and fetches the 44 pages on a schedule so freshness dates are real.

Handoff to IOMETE

Embeddable in Webflow as an iframe or custom code block. Bot handoff can point at the HubSpot portal already on the site. This is the route from demo to real tool.

07 · Proof, mapped to the rubric

How we show it works

CriterionWeightProof
Practical impact35%Before/after. The current site has one H1 for 12 pages and no role routing. Ours gives three visibly different first screens from the same atoms, plus a CRO export that pre-answers part of a vendor-risk file.
Buyer clarity25%15-second test. Five people outside the team watch the hero without sound and write one sentence on what IOMETE is. Pass if four say “runs in your own infrastructure” or equivalent.
Accuracy25%Ten fixed questions with known states. “Is it ISO 27001 certified?” → unknown. “Can it run air-gapped?” → claimed. “What does Enterprise cost?” → documented. Run five times each; one confident wrong answer fails. Show the refusal list executing live.
Working execution15%End to end: land → door → bot question → page moves → citation hover → export PDF.
